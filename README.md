# Solen — „strona za 500 zł” (do rolki 500 vs 3000)

Te same okulary i zdjęcia co w Solen® (https://nyjah2115.github.io/solen/), ułożone jak tani szablon sklepu sportowego:
czerwono-żółty, krój Impact, slider z napisem, pasek promocji, emoji zamiast ikon, „(0 opinii)”, newsletter,
niedziałająca mapa, baner cookies. Bez animacji i bez obrotu 360°. Marka zmyślona, to koncept.

Otwórz w Chrome/Safari na pełnym ekranie. Skróty: **A** auto-scroll (~16 s), **C** kursor, **0** góra,
**P** okienko z rabatem, **K** baner cookies.
